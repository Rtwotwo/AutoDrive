从论文到推文，四步完成
  1. 导入论文。输入 arXiv 链接或上传 PDF，等待文字与原图提取。
  2. 确认配图。在“原文与配图”检查裁剪区域、图号与表格，勾选写作时使用的图片。
  3. 生成与编辑。配置模型，选择侧重点和篇幅，生成后逐章调整文字并保存。没有 API 也能导出提示词、导入 JSON。
  4. 复核与导出。查看“证据核对”，下载图文包。将正文粘贴到公众号编辑器，逐张上传图片并检查移动端效果。
审核通过后可提交公众号草稿；公开发表与群发在微信后台完成。模型生成与作者观点均需人工复核；软件、源码和数据独立于 GitHub 仓库，均保存在本机。导入 arXiv 会联网下载论文；生成时会连接你指定的模型服务。
